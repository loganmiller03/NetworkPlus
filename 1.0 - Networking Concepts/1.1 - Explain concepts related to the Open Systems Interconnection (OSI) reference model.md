# 1.1 - Explain concepts related to the Open Systems Interconnection (OSI) reference model
* Application, Presentation, Session, Transport, Network, Data Link, Physical
* All People Need Seem To Need Data Processing
### Layer 1 - Physical Layer: cables, fiber and the signal itself
  * the physics of the network
    * signaling, cabling, connectors
    * this layer is not about protocols, just actual physical hardware
### Layer 2 - Data Link Layer: frames, MAC address, Extended unique Identifier (EUI-48, EUI-64), switch
  * the switching layer
  * the basic network language
    * foundation of communication
  * Data Link Control (DLC) Protocols
    * synonymous with the MAC address on Ethernet
### Layer 3 - Network Layer: IP address, router, packets
  * the routing layer
  * Internet Protocol (IP) address
  * fragments frames to traverse different networks
### Layer 4 - Transport Layer: TCP segments, UDP datagrams
  * the post office layer
  * responsible for getting data from one device to another
  * TCP (Transmission Control Protocol) and UCP (User Datagram Protocl)
### Layer 5 - Session Layer: control/tunneling protocols
  * Communication management between devices
    * start, stop, and restart sessions
  * control protocols, tunneling protocols
### Layer 6 - Presentation Layer: app encryption (SSL/TLS)
  * character encoding, application encryption/decryption often combined with layer 7
### Layer 7 - Application Layer: your eyes
  * the layer users see
  * HTTP, FTP, DNS, POP3
