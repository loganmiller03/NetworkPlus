# 1.2 - Compare and contrast networking appliances, applications, and functions
### Physical and Virtual Appliances
* routers - routes traffic between IP subnets
  * OSI layer 3 device, routers inside of switches sometimes called "layer 3 switches"
  * often connects diverse network types (LAN, WAN, copper, fiber)
* switch - bridging done in hardware
  * Application specicif integrated circuit (ASIC)
  * OSI layer 2 device - forwards traffic based on data link/MAC address
  * many ports and features, may provide PoE(power over ethernet)
* firewalls - filter traffic by port number or application
  * traditional vs NGFW
  * encrypt traffic via VPN between sites
  * most firewalls can be layer 3 devices(routers) often sitting on the ingress/egress of the network
  * to do so, they use NAT (Network Address Translation)
  * supports dynamic routing
* IDS/IPS (Intrusion Detection/Prevention Systems)
  * watch for known vulnerabilities and prevent or alert if detected on the network
  * checks for buffer overflows, XSS, common vulnerabilites
* Load Balancers - balance traffic across multiple servers
  * fault tolerance - outages have no effect
  * TCP offload - handles protocol overhead
  * SSL offload - handles encryption/decryption
  * caching - fast data response time
  * prioritization of traffic(one page gets more traffic and configures appropriately)
  * content switching - each server is dedicated to one app
* Proxy Servers - performs request on behalf of the user
  * sits between users and the external network
  * receives a users request, and performs request on behalf of the user, checking for various things before returning the result to the user
  * useful for caching, access control, URL filtering, content scanning
* Network Attached Storage (NAS) -
  * connect to a shared storage across the network
  * provides file level access
* Storage Area Network (SAN)
  * looks and feels like a local storage device
  * block level access, which gives more efficient reading and writing(file level access requires the whole file be overwritten for one update)
* Access Points (AP)
  * not a router, but a bridge
  * extends wired network onto wireless network
  * OSI layer 2 device
* Wireless LAN Controllers
  * centralized management of APs including monitoring performance, security, updates, etc.
  * configure and deploy new APs

### Applications
* Content Delivery Network (CDN)
  * geographically distributed caching servers so data can be accessed quicker

### Functions
* Virtual Private Network (VPN)
  * encrypt data over insecure channels
  * VPN concentrator - dedicated encryption/decryption, often integrated into a NGFW(hardware or software)
* Quality of Service (Qos)
  * traffic shaping, packet shaping
  * control network traffic by bandwidth usage or data rates
  * prioritize apps that get higher traffic
  * configure changes in routers, switches, firewalls, and QoS devices
* Time To Live (TTL)
  * how long data should be available
    * not all systems or protocols are self regulating
  * useful to stop routing loops
  * decide how long a task occurs by actual elapsed time or number of packet hops
    * TTL is part of the information in the IP packet(default for Windows is 128 hops, Linux/Mac is 64 hops)
      * every router hop decreases TTL by 1, and if TTL=0 the packet is dropped by the router
    * for DNS, TTL is defined in seconds
      * lookups are cached for TTL seconds as part of DNS server configuration
